# 🌹 Bloom & Balance Boutique

Bloom & Balance Boutique is a responsive e-commerce web application centered around self-care and wellness products, including journals, planners, candles, and teas.

I developed this project as a functional MVP to apply my computer science knowledge to a complete front-end application. The project combines responsive design, JavaScript functionality, data handling, debugging, and user-focused development.

## ✨ Features

- Browse a collection of self-care and wellness products
- Search for products
- Dynamically load product information from CSV data
- Add products to a shopping cart
- Remove products from the shopping cart
- Automatically update the cart item count
- Calculate and display the cart total
- Interactive cart modal
- Responsive and user-friendly interface

Main structure and content of the application.

`css/`
Contains the styling and responsive design for the website.

`js/`
Contains the JavaScript functionality for product loading, search, cart management, and user interaction.

`data/`
Contains the CSV product data used by the application.

`images/`
Contains product and website imagery.
